Versions `partprobe-ascii-stl-spike-v3` and `partprobe-binary-stl-spike-v3` produce provisional mesh evidence for:

- ASCII grammar or exact binary record framing identified from content and representation identified as mesh;
- unresolved/unknown source units requiring explicit confirmation;
- triangle count, axis-aligned extents, and surface area in source-coordinate units;
- undirected-edge manifold and watertight classification;
- paired-edge winding consistency;
- versioned `not_detected`, `detected`, or `indeterminate` self-intersection state;
- topology policy `partprobe-mesh-topology-policy-v1`, `exact_source_coordinates` identity, and explicit `welding_status: not_applied`;
- categorical `Low`/`NeedsReview` confidence with ordered validated reason codes; and
- enclosed volume and centroid only when the mesh is watertight, consistently wound, has nonzero finite signed volume, and self-intersection is `not_detected`.

Binary records require exact framing, finite normal/vertex components, and a zero attribute field; unsupported per-facet attribute/color payloads fail closed rather than being silently discarded. Failures expose stable content-free diagnostic codes for invalid limits, input/triangle quota breaches, invalid text/structure/numbers, unsupported attribute data, degenerate triangles, and empty meshes. Non-finite intermediate measurements fail closed rather than entering evidence.

Version `partprobe-3mf-spike-v8` validates an in-memory ZIP/OPC package before reading the selected model. It requires the exact OPC content-types and root-relationships parts, resolves one internal StartPart target, verifies the model content type, and never extracts a part to disk. Preflight uses raw ZIP-entry access so name, type, encryption, sizes, ratio, and declared compression can be classified without first invoking a decompressor. It rejects encrypted, non-file, unsafe-name, duplicated/case-fold-ambiguous, externally targeted, unsupported-compression, malformed XML, document-type/general-reference, unsupported-required-extension, and unsupported-model-structure inputs. Limits cover original bytes, entry count, aggregate expanded bytes, per-XML bytes, compression ratio, vertices, triangles, objects, component references, and model-level metadata entries. V8 supplies the same versioned self-intersection and confidence evidence as STL after every component/build/unit transform has been applied, retains Core vertex indices as topology identity, and explicitly reports `welding_status: not_applied`.

STL v3 and 3MF v8 use detector `partprobe-exact-mesh-intersection-spike-v1` plus confidence policy `partprobe-mesh-confidence-policy-v1`. Pairwise triangle checks are bounded by the existing 1,000-triangle ceiling, use exact floating-point AABB/predicate behavior, ignore ordinary shared-edge adjacency according to the source format's identity, and return `indeterminate` for overlapping-bounds coplanar pairs instead of guessing a tolerance. A unit-resolved manifold, watertight, consistently wound mesh with `not_detected` intersection reaches only `Low`; unresolved units, topology defects, `detected`, or `indeterminate` produce `NeedsReview`. Detected/indeterminate states add warnings and withhold enclosed volume and centroid. This changes successful evidence shape and closed-measurement availability, so callers must rebuild and pin the parser/detector/policy versions. No production/customer analyses exist; old spike results are not silently upgraded.

Successful fixture expectation schema v4 replaces the v3 boolean self-intersection field with mandatory `not_detected`, `detected`, or `indeterminate` mesh evidence. It retains categorical confidence/reasons, rejects mesh confidence above `Low`, requires detected/indeterminate states to carry the matching `NeedsReview` reason and warning, rejects those codes on `not_detected`, and forbids enclosed volume/centroid for detected or indeterminate intersection. All committed success expectations were explicitly upgraded; unsupported v1–v3 success records and legacy boolean values fail validation. This is a test-contract migration only: parser/detector/confidence behavior and production/customer data are unchanged, no persisted customer records exist, and the separate schema-v1 failure expectations remain unchanged because rejected inputs still produce no geometry evidence.

The bounded model contract accepts the 3MF Core namespace, every Core length unit plus its normative millimetre default, zero to the configured limit of unique well-known unprefixed model-level Core metadata entries, one leaf mesh object, zero or more bounded component objects that each contain exactly one reference to the immediately preceding object, and one build item targeting the last object. Component depth is therefore bounded by both `max_objects - 1` and `max_components`; no separate unbounded graph traversal exists. It enforces Core positive resource-ID bounds, uniqueness, and strict prior-object chain order. Vertices pass through every documented row-vector component transform from leaf to build, then the build transform, then canonical-millimetre conversion before entering the same format-neutral triangle measurement code as STL; this order follows the Consortium's [Core 1.4 model, metadata, matrix, component, and build rules](https://github.com/3MFConsortium/spec_core/blob/master/3MF%20Core%20Specification.md). Metadata text and names are never retained; evidence exposes only total and `preserve=true` counts and adds `THREE_MF_METADATA_NOT_INTERPRETED`. Evidence also distinguishes an explicit `unit` attribute from the Core default; retains leaf/build counts and IDs; represents component absence as an empty chain, not zero-like IDs; and retains every link's object ID, referenced ID, exact 12-value source-unit transform, and applied-state flag. Duplicate/unknown/vendor metadata, unsupported metadata attributes/types, object/item metadata groups, singular or reflected transforms, multiple references per component object, branching, non-immediate references, unions, extra/unused objects, multiple build items, materials, and unknown structures fail visibly rather than being flattened, unioned, interpreted, or ignored.
